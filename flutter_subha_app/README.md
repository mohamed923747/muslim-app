# 🕌 تطبيق زاد المسلم (Flutter Edition)

تطبيق إسلامي عصري وشامل تم بناؤه باستخدام **Flutter** بأحدث معايير **Material 3** مع دعم كامل للغة العربية والاتجاه من اليمين لليسار (RTL) والأوضاع المضيئة والليلية الفخمة.

---

## 📱 مميزات التطبيق

1. **الرئيسية الذكية (Home Dashboard)**:
   - بطاقة الصلاة القادمة مع عد تنازلي حي ومباشر حتى وقت الأذان.
   - شريط مواقيت الصلاة لليوم كاملاً.
   - آية وتدبر يومية متجددة.
   - بنر المساعد الإيماني الذكي.
   - وصول سريع لكافة أقسام التطبيق.

2. **المساعد الصوتي والإيماني الذكي (AI Companion)**:
   - مدعوم بـ **Google Gemini API**.
   - إجابة فورية على الأسئلة الدينية والفقهية وتفسير الآيات.
   - تنفيذ الأوامر والملاحة الصوتية السريعة (مثل: *افتح السبحة*، *اقرأ القرآن*، *أين القبلة*).

3. **المصحف والقرآن الكريم (Quran Reader)**:
   - فهرس السور مع عدد الآيات ومكان النزول (مكية / مدنية).
   - قارئ قرآن متطور مع إمكانية تكبير وتصغير حجم الخط باللمس.
   - شريط بحث فوري عن السور بالاسم أو الرقم.
   - إمكانية نسخ الآيات بنقرة زر.

4. **حصن المسلم والأذكار (Azkar & Adhkar)**:
   - أذكار الصباح، المساء، بعد الصلاة، النوم، الاستيقاظ، السفر، والرقية الشرعية.
   - عداد تنازلي تفاعلي مع استجابة لمسية (Haptic feedback) وتحديد الأذكار المكتملة.

5. **السبحة الإلكترونية الكبرى (Digital Subha)**:
   - حبات سبحة واقعية متحركة بسحب وإفلات اللمس العمودي.
   - قرص دائري مضيء يوضح نسبة الإنجاز للهدف (33، 99، 100، أو مفتوح).
   - قائمة لاختيار صيغ التسبيح المختلفة (سبحان الله، الحمد لله، الاستغفار، الصلاة على النبي...).
   - إحصائيات إجمالي التسبيحات في الجلسة.

6. **بوصلة اتجاه القبلة (Qibla Compass)**:
   - مؤشر دقيق لزاوية واتجاه الكعبة المشرفة بمكة المكرمة.

7. **متتبع العبادات والسنن اليومية (Worship Habit Tracker)**:
   - قائمة الفرائض الخمس، السنن، ورد القرآن، وصلاة الوتر والضحى.
   - شريط إنجاز يومي وحفظ تلقائي لحالة كل يوم في الذاكرة المحلية (`SharedPreferences`).

8. **الإعدادات والتخصيص (Settings)**:
   - التبديل السلس بين المظهر الفاتح والداكن والليلي والتلقائي.
   - إدخال وحفظ مفتاح Gemini API.

## 🚀 طريقة تشغيل المشروع (How to Run)

### 1. تثبيت الحزم (Install Dependencies)
في موجه الأوامر داخل مجلد المشروع:
```bash
cd flutter_subha_app
flutter pub get
```

### 2. التشغيل على أجهزة Android أو المحاكي (Run on Android):
```bash
flutter run
```

### 3. التشغيل على المتصفح والويب (Run on Web):
```bash
flutter run -d chrome
```

### 4. بناء نسخة الإنتاج النهائية (Build Release APK):
```bash
flutter build apk --release
```
ستجد ملف الـ APK الجاهز للتثبيت في:
`build/app/outputs/flutter-apk/app-release.apk`
